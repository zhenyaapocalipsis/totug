# L10n-4f — журнал и всплывающие сообщения

- EventText отображает машинные события на выбранном языке (121 шаблон/подпись), использует карточный и географический каталоги, учитывает пользовательские имена и формы количества карт. Английское описание старого API EventLogPanel.describe сохраняется.
- Журнал хранит исходные события, а не готовые переводы. При смене языка обновляется показанная история; остаются те же события и очередь, лимит 300 строк, пауза между строками, подсветка свежей строки и прокрутка. Пользовательские заметки остаются буквальными.
- Уведомления GameScreen (таймер, сетевой вход/выход игроков, зритель, повтор, режим бога и отказы действий) переводятся по исходным строкам. Активная подсказка сохраняет Tween, время и прозрачность. Вместе с решениями каталог содержит 247 строк/шаблонов.
- Распознавание шаблонов сначала предпочитает известный буквальный префикс; иначе общий шаблон места мог перехватить Not allowed. Подстановки завершаются до разбиения по тире.
- Недоступные шрифту кавычки заменены обычными; проверка символов теперь покрывает и отдельный каталог решений/уведомлений. Имена игроков с квадратными скобками в журнале экранируются как буквальный текст.
- Известные дополнительные типы событий получили русские подписи без вывода дополнительных скрытых полей. Неизвестный тип будущей версии сохраняет исходный идентификатор как резерв.
- Журнал не добавлялся заново на игровой экран: перевод относится к существующему компоненту. Карточный каталог завершается в L10n-5; его имена автоматически подставляются в события.

Проверки: localization_events.gd — 425/0; localization_decisions.gd — 267/0; localization.gd — 16927/0; localization_turn_piles.gd — 33/0; localization_match.gd — 7/0; run_tests.gd — 2269/0. Сеть и механические данные не менялись.
