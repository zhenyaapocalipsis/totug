# L10n-4g — итоги, награды и рекорды

- Переведены победитель/ничья, досрочное завершение, статьи очков, кнопки, заголовки итоговых колод, рейтинг, ящики, пыль и рекорды (37 ключей).
- Подробные подсказки поясняют сокращённые статьи итогового счёта.
- Переключение обновляет существующие подписи, не вызывает update_from_view, не пересоздаёт таблицу или итоговые карты, не меняет очки и награды и не открывает спрятанные кнопкой ДОСКА итоги.
- Размеры ячеек заранее учитывают оба языка. Для этого сервис получил text_for(language, key, parameters): он разрешает вложенные подписи без переключения глобального языка и без уведомлений интерфейса.
- RecordText использует устойчивые идентификаторы RecordBook; серверные таблицы и исходный API названий рекордов не менялись.
