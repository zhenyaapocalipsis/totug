TYRANTS OF THE UNDERDARK — English / Русский

Распакуйте архив и запустите TyrantsOfTheUnderdark.exe.
Файл TyrantsOfTheUnderdark.pck должен оставаться рядом с exe.

Язык: SETTINGS / НАСТРОЙКИ → English / Русский. Выбор сохраняется.
Переключатель доступен также в настройках во время партии.

Для игры с друзьями создайте лобби и передайте им код комнаты.
Друзья вводят код и присоединяются; создатель запускает партию.
Для рейтинговой игры используйте SEARCH / ПОИСК.
Адрес сервера уже указан в игре.

Esc — меню партии. F11 — полный экран. Остальные клавиши можно
посмотреть и изменить в настройках; правила доступны в обучении.

При запуске игра автоматически проверяет обновления. Размер загрузки
зависит от вашей версии: используется патч или полный пакет игры.
