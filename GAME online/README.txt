TYRANTS OF THE UNDERDARK — онлайн

Запуск: распакуйте архив в любую папку (например, на Рабочий стол) и откройте
TyrantsOfTheUnderdark.exe. Файл TyrantsOfTheUnderdark.pck должен лежать рядом с ним.

Обновления приходят сами: при запуске игра проверяет сервер и, если есть
новая версия, скачивает её (~10 МБ) и перезапускается. Ничего делать не нужно.

Если Windows покажет «Система Windows защитила ваш компьютер»:
«Подробнее» -> «Выполнить в любом случае».

Игра с другом через интернет:
1. Один игрок: CREATE 2 -> CREATE ROOM. Появится код комнаты из 4 букв.
2. Второй игрок: JOIN CODE -> вводит код -> JOIN.
3. Первый игрок нажимает START.

Поле SERVER трогать не нужно (адрес уже вписан).
Tab — расклад игроков, чат и журнал. Esc — меню.

Рейтинг: онлайн-партии идут в рейтинг (старт 1000). Он привязан к вашему компьютеру
(файл профиля), а не к имени.
