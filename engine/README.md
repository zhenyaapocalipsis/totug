# Tyrants of the Underdark → Godot 4

Полностью автоматизированная цифровая версия. Мультиплеер, ПК.
Архитектура — в документе проекта `architecture.md` (в Claude).

## Как запустить

Нужен **Godot 4.7** (достаточно headless-сборки). На момент написания
актуальна 4.7.2. Ядро правил не использует ничего версионно-специфичного, но
держаться стоит поддерживаемой ветки: у 4.4 security-поддержка закончилась
в марте 2026, 4.3 и старше — тем более вне поддержки.

```bash
# первый запуск и после добавления нового class_name
# (без этого глобальные class_name не регистрируются и скрипты не находят классы)
godot --headless --path godot --import

# тесты ядра правил
godot --headless --path godot --script res://tests/run_tests.gd

# диагностика сборки доски
godot --headless --path godot --script res://tests/diagnose_board.gd
```

## Конвейер данных

`data/board/*.json` **порождаются**, править нужно инструменты, а не JSON.
Полный проход, в порядке зависимостей:

```bash
HEX="путь/к/board hexes"

python3 tools/extract_board_data.py          # 1. Lua -> JSON
python3 tools/calibrate_hexes.py    "$HEX"   # 2. масштаб/центр по арту (диагностика)
python3 tools/snap_slots_to_art.py  "$HEX"   # 3. слоты -> центры печатных кругов
cp data/board/*.json godot/data/board/
```

Шаг 3 перезаписывает координаты в `site_data.json` и `route_slots.json`,
поэтому после повторного шага 1 его нужно прогонять снова.

## Сверка данных с печатным артом

Координаты из мода TTS оцифрованы человеком на глаз. Сверка по картинкам
(шаги 2-3) сажает каждый слот точно в центр печатного круга и заодно ловит
ошибки оцифровки.

Итог сверки: **241 слот из 242 сел на печатный круг**, общий масштаб оказался
константой 127.92 px на единицу арта при картинке 1816 px (разброс по 25 гексам
0.4 px, то есть 0.3%). Нашлись две расхождения с артом:

1. **B1, кольцо на север** — в Lua `{-0.47, 4.400}`, на арте кольцо стоит по
   центру, около `{-0.05, 4.40}`. Ошибка 59 px. Лечится снапом автоматически.
   Побочный эффект был неприятный: одна кривая точка перекашивала подгонку
   всего гекса, из-за чего «уезжали» все остальные слоты B1.
2. **A7** — в Lua ему приписан общий с A4-A8 список из 7 колец («shared across
   all five since they use the same template»). Для A4/A5/A6/A8 это верно
   (совпадение до 0.01 единицы), но у A7 на арте **одно** кольцо в центре и
   6 туннелей прямо к рёбрам. Лишние 6 троп-слотов — это лишние места под
   войска, то есть прямое влияние на правила. Правится через
   `ROUTE_SLOT_OVERRIDES` в `extract_board_data.py`.

Единственный слот без печатного круга — центральный на A8: детектор его не
увидел, но A4/A5/A6 подтверждают, что кольцо там есть, поэтому слот остаётся
с координатой из Lua.

Проверить глазами любой гекс:

```bash
python3 tools/render_graph_overlay.py C7 "$HEX" overlay_C7.png
```

## Смежность: почему размечена вручную

Смежность решает, где у игрока есть Присутствие, а значит куда можно ставить
войска и кого атаковать. Вывести её автоматически не получилось:

- **геометрия врёт системно** — на C4 у кольца r0 настоящие соседи Red Gate и
  Caer Sidi, а два ближайших по расстоянию — Caer Sidi и Iblith;
- **трассировка туннелей по картинке не сходится** — арт непоследователен:
  у C1 карточка и туннели образуют одну белую область, у C7 их разделяет
  чёрная обводка. Пять разных подходов чинили одни тайлы и ломали другие.

Поэтому смежность размечена вручную по рисунку всех 27 тайлов. Полный разбор —
в документе проекта `art-verification.md`.

## Два правила, подтверждённые владельцем игры

1. **Локации, соединённые туннелем без троп-слотов, считаются соседними.**
   Войско в одной даёт Присутствие в другой. Связь не транзитивна.
2. **Локации, к которым не подходит ни один туннель, — намеренный дизайн**
   (The Barrens на X1, Indifference на X2). Попадают туда шпионом: по рулбуку
   его можно поставить на любую локацию без Присутствия, а шпион уже даёт
   Присутствие. Поэтому доска НЕ обязана быть одной связной компонентой.

## Три ошибки в исходных данных мода

Найдены сверкой с печатным артом:

1. **B1** — кольцо на север смещено на 59 px. Лечится снапом автоматически.
2. **A7** — 7 троп-слотов вместо 1. Лишние места под войска влияют на правила.
3. **A2** — два фантомных слота: они стоят внутри блока с правилами региона,
   поверх букв. Это вообще не места под войска.

Пункты 2 и 3 правятся через `ROUTE_SLOT_OVERRIDES` в `extract_board_data.py`.
