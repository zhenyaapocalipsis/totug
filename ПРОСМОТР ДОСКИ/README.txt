ПРОСМОТР СОБРАННОЙ ДОСКИ - как запустить
=========================================

1. Двойным щелчком запусти файл   build-viewer.bat
   Он склеит программу из частей (пара секунд) и сам удалит части.

2. Появится файл   board-viewer.exe
   Запусти его двойным щелчком.

Windows может предупредить, что издатель неизвестен - программа не
подписана цифровой подписью. Нажми "Подробнее" -> "Выполнить в любом случае".

УПРАВЛЕНИЕ
----------
мышь с зажатой левой кнопкой  - двигать доску
колесо мыши                   - приблизить / отдалить
пробел                        - пересобрать доску заново
S                             - показать/скрыть точки
Esc                           - выход

ЧТО ЭТО ПОКАЗЫВАЕТ
------------------
Доску на 2 игроков, собранную самим движком игры: те же гексы, те же
повороты, те же места под войска, что будет использовать игра.
Зелёные точки - места под войска на локациях, оранжевые - на туннелях.

Пробел пересобирает доску с новым случайным раскладом, как перетасовать
тайлы перед партией.

В левом верхнем углу - цифры прямо из движка. "Компонент связности 1"
означает, что вся карта связна. Если там появится 2 или больше - доска
собралась с оторванным куском, и это надо чинить.

СТАРЫЕ ФАЙЛЫ
------------
Файлы с русскими именами (собрать-программу.bat и ПРОЧТИ-МЕНЯ.txt)
можно удалить - они заменены этими.
