# План доработки Tyrants of the Underdark (Godot)

Составлен 2026-09-15 по ответам владельца игры.

## Решения, которые уже приняты

| Вопрос | Решение |
|---|---|
| Цели | полировка и баги, игра по сети, 4 игрока, выбор полуколод |
| Бот | не нужен |
| Правила/доска | только Demonweb |
| Язык игры | английский |
| Графика | настоящие картинки карт, анимации, аккуратнее вёрстка (без звука) |
| 4 игрока | только по сети; на одном экране — только 1v1 |
| Сеть | один игрок хостит, остальные подключаются по IP (через интернет — Radmin VPN); сервер хранит истинное состояние, есть сохранение и переподключение |
| Процесс | этапы; после каждого — автотесты + ваша проверка в игре; баги пишете в чат со скриншотом |
| Время владельца | 1–3 часа в неделю, значит одна проверка ≈ 30–40 минут |
| Резервные копии | локальный git, точка сохранения после каждого этапа |

## Как проходит каждый этап

1. Я читаю только нужные файлы и делаю изменения.
2. Прогоняю автотесты (`run_tests.gd`), для новых правил добавляю тесты.
3. Делаю коммит в git: «Этап N: …».
4. Даю короткий чек-лист: что запустить и на что посмотреть (5–10 пунктов).
5. Вы играете и пишете в чат: «ок» или баги со скриншотами.
6. Исправляю баги, коммит, переходим к следующему этапу.

## Этапы

### Этап 0 — подготовка (≈1 сессия, вам проверять почти нечего)
- `git init`, `.gitignore` (папка `.godot/`, exe-сборки), первый коммит.
- Проверить, что все тесты проходят сейчас (исходная точка).
- Короткий `CLAUDE.md` в проекте: как запускать и тестировать, ссылка на этот план.

### Этап 1 — аудит (вы проверяете ≈30 мин)
- Сверить все 125 карт в `cards.json` с книгой правил, сканами и Lua-данными TTS; список подозрительных эффектов.
- Сверить базовые правила (ход, контроль, конец игры, подсчёт очков) с правилами Demonweb.
- Результат: файл `audit.md` — таблица «проблема / где / насколько серьёзно». Вы подтверждаете спорные пункты.

### Этап 2 — исправление эффектов карт и правил
- Исправить всё из аудита пачками по полуколодам (одна полуколода = одна проверка).
- На каждую исправленную карту — автотест.

### Этап 3 — удобство интерфейса
- Понятно показывать: чей ход, сколько Power/Influence, что можно сделать сейчас.
- Подсветка доступных целей на доске, отмена незавершённого выбора там, где это разрешено правилами.
- Лог событий читается без усилий.

### Этап 4 — внешний вид
- Нарезать листы карт из папки `cards` (листы в формате TTS) на отдельные картинки и показывать их в руке и на рынке.
- Аккуратная вёрстка: шрифты, цвета, отступы.
- Простые анимации: карта летит из рынка/в сброс, появление войск и шпионов.

### Этап 5 — выбор полуколод
- Экран перед партией: выбрать любые 2 из 6 полуколод (или случайно).
- Тесты: рынок собирается правильно для всех 15 сочетаний.

### Этап 6 — сеть 1v1
- Экран «Создать игру / Подключиться по IP».
- Используем уже готовые `GameServer` / `Intent` / `StateView`: каждый игрок видит только свою руку.
- Проверка: два окна на одном компьютере, потом с другом через Radmin VPN.

### Этап 7 — сохранение и переподключение
- Хост автоматически сохраняет партию после каждого действия.
- Игрок, у которого оборвалась связь, заходит под тем же именем и продолжает.
- Хост может загрузить сохранённую партию после перезапуска.

### Этап 8 — 4 игрока (по сети)
- Раскладка доски Demonweb на 4 игроков, стартовые настройки и порядок хода на 4.
- Интерфейс вмещает панели четырёх игроков.
- Проверка: 4 окна на одном ПК, потом живая партия.

### Этап 9 — сборка релиза
- Обновлённый exe и README (как хостить и как подключиться).
- Финальная живая партия.

## Риски и что с ними делаем
- **Тексты карт после OCR могут быть неверными.** Спорные случаи решает владелец, решения записываются в память.
- **Через интернет подключение по IP не работает без VPN или проброса порта.** Сначала Radmin VPN; свой сервер можно добавить позже, не переделывая игру.
- **Мало времени на проверку.** Этапы маленькие, проверка по чек-листу, а всё, что можно, ловят автотесты.

## Что пока не решено (не мешает начать)
- Публиковать ли игру (от этого зависят лицензии на арт и выбор Steam или своего сервера).
- Нужны ли звуки позже.
